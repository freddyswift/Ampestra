# Security Policy

## Supported versions

Security fixes are provided for the latest published release of Ampestra.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/freddyswift/Ampestra/security/advisories/new)
so the report and any supporting details remain private while they are
investigated.

Include the affected Ampestra version, macOS version, reproduction steps, and
the impact you observed. Do not include speaker credentials, network captures,
private addresses, or other personal data unless they are essential; redact
them whenever possible.

Ampestra is an unofficial, independent project and is not affiliated with or
endorsed by KEF.
